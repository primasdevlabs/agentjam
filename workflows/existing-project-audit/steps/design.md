# Step 4: Audit Frontend & Design System

1. Locate existing design tokens (`tokens.css`, `theme/`, CSS variables).
2. Scan for inline hardcoded colors (`text-[#344C36]`, `style={{...}}`) and custom spacing.
3. Audit icon usage: check for emoji UI icons (`🚀⚡🔥`) or multiple icon libraries.
4. Flag generic AI visual slop (glow borders, unguided backdrop blurs, floating blobs).
5. Audit product copy for AI marketing buzzwords ("empower", "unlock", "supercharge").
