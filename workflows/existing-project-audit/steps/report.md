# Step 7: Generate House Cleaning Report

Format findings into a structured House Cleaning Report categorized into:
- **Critical**: Must be resolved before new feature work (e.g. security risks, broken builds).
- **Recommended**: Highly advised refactorings (e.g. consolidate icon libraries, extract inline design tokens).
- **Optional**: Minor cleanups (e.g. formatting alignment, unused import removal).

> **Rule**: Present findings before making destructive modifications.
