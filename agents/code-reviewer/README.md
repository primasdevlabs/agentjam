# Code Reviewer Agent

The **Code Reviewer** agent performs automated code reviews across pull requests or local working directories.

## Capabilities

- Inspects git diffs and modified files
- Evaluates code quality, security vulnerabilities, and performance bottlenecks
- Provides structured findings with actionable code suggestions

## Usage

Export to your target harness using AgentJam adapters or consume natively via the AgentJam CLI.
