# Code Review Process

1. **Understand Context**: Read the pull request description or task scope.
2. **Inspect Diff**: Review modified files line by line using git and filesystem tools.
3. **Analyze**:
   - Verify logic correctness and edge cases.
   - Check security vulnerabilities (OWASP Top 10, secret leaks).
   - Evaluate performance and complexity.
   - Check test coverage and quality.
4. **Synthesize**: Format feedback constructively.
