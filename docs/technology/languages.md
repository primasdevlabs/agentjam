# Supported Language Ecosystems

AgentJam indexes 15 programming language categories under `languages/`:

| Ecosystem | Primary Languages | Default Tooling |
| :--- | :--- | :--- |
| **Web** | TypeScript, JavaScript, HTML, CSS | ESLint, Prettier, tsc, Vitest |
| **Backend** | PHP, Python, Go, Java, Kotlin, C# | Pint/PHPStan, Ruff/Mypy, golangci-lint, SpotBugs |
| **Systems** | Rust, C, C++ | cargo clippy, clang-tidy, cppcheck |
| **Mobile** | Swift, Kotlin, Dart/Flutter | SwiftLint, ktlint |
| **Data & Query** | SQL | sqlfluff |
