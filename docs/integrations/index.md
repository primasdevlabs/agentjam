# Harness & Environment Integrations

1. **IDE**: VS Code, Cursor, Windsurf.
2. **Autonomous Agents**: Devin, Agentless, AutoGPT.
3. **CLI**: Claude Code, Goose, Aider, Gemini CLI.
4. **Extensions**: Cline, Roo Code, GitHub Copilot Chat.
5. **AI Platforms**: OpenAI Assistants, LangChain, LlamaIndex.
6. **Generic**: Standard Markdown / System Prompt fallback.
