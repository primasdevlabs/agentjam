# AgentJam Workflows

Workflows orchestrate multi-step agent interactions:

* **existing-project-audit**: 7-step audit of codebase architecture, security, and design tokens.
* **new-project**: Scaffolding new projects with AgentJam rules.
* **feature-development**: End-to-end research, implementation, testing, and review.
* **bug-fixing**: Log analysis, reproduction test case, root cause fix, and verification.
* **code-review**: Policy and security audit of pull requests.
* **ui-development**: Design discovery, token-based component creation, anti-slop review.
* **dependency-update**: Controlled package upgrade and test verification.
* **framework-update**: Major framework migration with ADR creation.
* **release**: Pre-release audit, tagging, and changelog generation.
