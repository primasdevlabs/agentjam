# AgentJam Composed Agents

AgentJam provides composed agents combining specialized roles, skills, tools, and policy constraints:

- **software-engineer**: Full-stack feature developer.
- **frontend-engineer**: UI specialist with design governance & anti-slop rules.
- **backend-engineer**: Service, API, and database architect.
- **code-reviewer**: Policy & security compliance auditor.
- **qa-engineer**: Automated testing specialist.
- **security-engineer**: OWASP, vulnerability, and secret auditor.
- **ui-ux-designer**: Visual system & design token architect.
- **architect**: System boundaries & domain architect.
- **researcher**: Up-to-date documentation & library researcher.
