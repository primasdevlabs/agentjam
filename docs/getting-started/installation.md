# Installation & Setup

## Installation
Install `@agentjam/runtime` or `@agentjam/cli` via npm or pnpm:

```bash
npm install @agentjam/runtime @agentjam/validator
```

## Initializing in a Project
Run the initialization command inside any workspace:

```bash
npx agentjam init
```

This creates a local `.agentjam/` configuration folder containing project rules, stack binding, and design governance policies.
