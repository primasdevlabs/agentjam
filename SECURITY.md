# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within AgentJam or any of its canonical resources, please do NOT create a public GitHub issue.

Instead, please report security concerns via email to `security@agentjam.org` or open a private security advisory on GitHub.

## Guidelines

- Never store API keys, tokens, or credentials in canonical AgentJam manifests or instructions.
- Ensure all tool capabilities declare explicit safety levels (`read-only`, `safe-write`, `destructive`).
