# Anti-Slop Skill Instructions

## Core Rules
1. Reject generic Inter/Roboto defaults when project specifies custom typography (e.g. Noto).
2. Reject indigo/violet glowing dark mode gradients (`from-purple-600 to-indigo-600`).
3. Reject emoji UI icons (`🚀⚡🔥`). Use SVG icons (Lucide, Heroicons, Tabler).
4. Reject feature card grids with identical 3-column structures and glowing borders.
